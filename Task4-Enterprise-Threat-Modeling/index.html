01 / Reference architecture

Illustrative trust boundaries and major enterprise components.

🌐Internet / Remote UserUntrusted network
🧱Firewall + WAFFilter & rate-limit
🔐Identity ProviderMFA + conditional access
🖥️Business ApplicationAuthenticated access
↓ verified, least-privilege access ↓
👩‍💻Managed EndpointsEDR + patching
🗂️File / Data ServerRBAC + encryption
📈Central Logging / SIEMAlerts + audit trails
💾Protected BackupsIsolated + tested restore

Design principle: each access request is authenticated and authorized; network location alone does not grant trust. Diagram is conceptual and not a deployed network.

Baseline defenses to reduce the identified risks.

✓
Least privilegeRole-based access; separate admin accounts.
✓
Assume breachNetwork segmentation, EDR, centralized alerts.
✓
Protect dataEncryption, retention rules, tested backups.
✓
Maintain visibilityLog identity, endpoint, server and application events.
